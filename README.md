# Application Météo Toulouse

Application console permettant de consulter l'historique météo de différentes stations de l'agglomération toulousaine depuis un fichier CSV en local ou via l'API Open Data.

## Prérequis

- **Python** : Version 3.12.4 

## Démarrage

Pour lancer l'application :

```bash
docker compose run --rm --build app
```

## Informations

Les derniers enregistrements de la station Carmes date du 26-03-2024.
Les fichiers csv ne sont pas forcément à jour, il faut privilégier l'API.
